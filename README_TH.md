# N1V65 Dash — แอปหน้าปัด OBD2 บน Android (Flutter)

## มีอะไรบ้าง
- **10 หน้าปัด** (ปัดซ้าย/ขวาเพื่อสลับหน้า และเลือกเปิด/ปิดแต่ละหน้าได้ใน MENU → หน้าปัด) ตัวเลขกับเข็มวิ่งนุ่มตามรีเฟรชเรตของจอ
  1. จอดิจิทัลแบบรถแข่ง: ไฟ shift 12 ดวง แถบรอบทรงลาด เกียร์ตัวใหญ่
  2. เกจกลมมีเข็ม: วัดรอบมีโซนแดง และเกจความร้อนแบบครึ่งวง
  3. Sweep: แถบรอบโค้ง (ขาว/เหลือง/แดง) ความเร็วอยู่กลาง และตาราง 6 ช่อง
  4. Arc: วงรอบสีเหลืองมีเกียร์อยู่กลาง ความเร็วในกล่องใหญ่ บูสต์ แบต และแถบความร้อน
  5. Yellow box: ช่องสีเหลือง 9 ช่อง และเกียร์กล่องสีฟ้า
  6. Bar graph: กราฟแท่งรอบทรงลาด 8 ช่องมีช่วงค่ากำกับ และเกียร์อยู่กลาง
  7. Red stripe: เกจรอบวงใหญ่บนพื้นแถบแดง มี 4 ค่าด้านขวา และไฟ shift ด้านล่าง
  8. ECU: รอบตัวใหญ่ แถบรอบไล่สี เกียร์และความเร็วกลางจอ และแถวค่าด้านล่าง
  9. Center tach: เกจกลางจอเหลือง/แดง มีช่องค่าซ้าย 4 ช่อง ขวา 4 ช่อง
  10. พื้นหลังเป็นรูปของคุณเอง (JPG/PNG/**GIF**): ถ้าใส่หลายรูปจะเปลี่ยนรูปตามช่วงรอบ
- ค่าที่แสดงเพิ่ม: **BOOST** (คำนวณจาก MAP − 101.3 kPa), **FUEL %** (PID 2F) และ **TRIP** (คำนวณจากความเร็ว รีเซ็ตได้ในเมนู)
- **แหล่งข้อมูล 4 แบบ** (เลือกได้ที่ MENU → การเชื่อมต่อ)
  - Demo จำลองค่า ใช้ทดสอบหน้าจอ
  - ELM327 Bluetooth ต่อ Vgate iCar Pro ตรงจากมือถือ
  - ELM327 WiFi
  - ESP32 CYD ผ่าน WiFi: ESP32 อ่าน OBD2 แล้วส่งค่ามาที่มือถือ ทำให้จอ CYD กับมือถือโชว์ค่าพร้อมกัน
- **DTC**: อ่านรหัสและลบรหัส มีคำอธิบายภาษาไทยสำหรับรหัสที่พบบ่อย
- **เกียร์**: แอปเดาเกียร์จากอัตราส่วนความเร็วต่อรอบ และกด "จำค่า" ขณะขับเพื่อคาลิเบรตแต่ละเกียร์ได้
- **ตั้งค่า**: รอบสูงสุด, redline, รอบที่ไฟ shift เริ่มติด, ความเร็วสูงสุด, อุณหภูมิที่เตือนความร้อน, เปิดจอค้าง และกลับจอ 180°

## วิธี build บน Windows
1. ติดตั้ง **Flutter SDK** (https://docs.flutter.dev/get-started/install/windows/mobile) และ **Android Studio**
   แล้วรัน `flutter doctor` ให้ขึ้นเครื่องหมายถูกในส่วน Android toolchain
2. เปิด Command Prompt ในโฟลเดอร์ที่จะเก็บโปรเจกต์ แล้วรัน (ต้องใช้ชื่อตามนี้เป๊ะ ๆ เพราะชื่อแพ็กเกจต้องตรงกับไฟล์ Kotlin)
   ```
   flutter create --org com.n1v65 --platforms android n1v65_dash
   ```
3. แตกไฟล์ zip นี้ในโฟลเดอร์เดียวกับที่รันคำสั่งข้อ 2 (ใน zip มีโฟลเดอร์ `n1v65_dash` อยู่ข้างใน ไฟล์จะลงทับโปรเจกต์พอดี) แล้วกด **แทนที่ไฟล์ทั้งหมด**
   (ไฟล์ที่จะถูกทับ: `pubspec.yaml`, `lib/`, `test/`, `android/app/src/main/AndroidManifest.xml`, `MainActivity.kt`)
4. รันคำสั่ง
   ```
   cd n1v65_dash
   flutter pub get
   flutter run                 (ต่อมือถือผ่าน USB และเปิด USB debugging ก่อน)
   flutter build apk --release (ถ้าจะสร้างไฟล์ติดตั้ง)
   ```
   ไฟล์ APK จะอยู่ที่ `build\app\outputs\flutter-apk\app-release.apk`

## ใช้กับ Vgate iCar Pro (Bluetooth 3.0)
1. จับคู่ Vgate ในหน้าตั้งค่า Bluetooth ของมือถือก่อน (PIN มักเป็น 1234 หรือ 0000)
2. ในแอปไปที่ MENU → การเชื่อมต่อ → ELM327 Bluetooth → เลือก → แตะชื่อ Vgate
3. เปิดสวิตช์กุญแจไปที่ ON หรือติดเครื่อง แล้วรอจนจุดสถานะมุมซ้ายบนเป็น**สีเขียว**

> Vgate ต่อได้ทีละอุปกรณ์ ถ้า ESP32 CYD ต่อ Vgate อยู่ มือถือจะต่อไม่ได้ ถ้าอยากให้แสดงพร้อมกันทั้งสองจอให้ใช้โหมด ESP32

## โหมด ESP32 CYD (ใช้ OBD2 ตัวเดียว แสดงพร้อมกันทั้งจอ CYD และมือถือ)
นำไฟล์ `esp32/N1V65Link.h` ไปวางไว้ในโฟลเดอร์สเก็ตช์เดิม แล้วเพิ่มโค้ดตามนี้
```cpp
#include "N1V65Link.h"

// (ไม่บังคับ) ให้แอปสั่งอ่าน/ลบ DTC ผ่าน ESP32 ได้
String myDtcRead() {
  // เรียกฟังก์ชันอ่าน DTC ที่มีอยู่เดิม แล้วคืนค่าเป็น JSON array
  return "[\"P0133\"]";   // ตัวอย่าง
}
bool myDtcClear() {
  // เรียกฟังก์ชันลบ DTC ที่มีอยู่เดิม
  return true;
}

void setup() {
  // ... โค้ดเดิม ...
  n1link::onDtcRead  = myDtcRead;
  n1link::onDtcClear = myDtcClear;
  n1link::begin();            // ESP32 ปล่อย WiFi ชื่อ "N1V65-DASH" รหัส 12345678
}

void loop() {
  // ... โค้ดเดิมที่อ่าน OBD2 และวาดจอ ...
  n1link::loop();
  n1link::send(rpm, speed, coolant, iat, volt, load, tps, map, maf, fuel); // ค่าที่ไม่มีให้ใส่ NAN (MAP ใช้คำนวณ BOOST)
}
```
ฝั่งมือถือ: ต่อ WiFi `N1V65-DASH` → ในแอปไปที่ MENU → การเชื่อมต่อ → ESP32 CYD (ค่าเริ่มต้นคือ 192.168.4.1 : 3333)
ถ้ามือถือแจ้งว่า "WiFi นี้ไม่มีอินเทอร์เน็ต" ให้กด **คงการเชื่อมต่อไว้**

**ข้อควรระวัง:** การเปิด WiFi ใช้ RAM ของ ESP32 เพิ่มประมาณ 40–50 KB และ WiFi ต้องแบ่งเสาอากาศใช้ร่วมกับ Bluetooth
ถ้าจอ CYD มีอาการค้างหรือรีบูตอยู่แล้ว อาจเป็นหนักขึ้น ควรลองโดยยังไม่ฝังภาพ GIF ขนาดใหญ่ก่อน

## โครงสร้างโค้ด
```
lib/
  main.dart                 เริ่มแอป: ล็อกจอแนวนอน, เปิดจอค้าง
  settings.dart             ค่าตั้งทั้งหมด (บันทึกถาวร)
  data/
    hub.dart                ศูนย์กลางข้อมูล + สถานะการเชื่อมต่อ
    elm_source.dart         ELM327 (Bluetooth/WiFi): init, วนอ่าน PID, อ่าน/ลบ DTC
    esp32_source.dart       รับ JSON จาก ESP32
    demo_source.dart        โหมดจำลอง
    native.dart             ช่องทางคุยกับ Kotlin
  ui/
    dash_shell.dart         หน้าหลัก ปัดสลับหน้า + ปุ่ม MENU
    race_dash.dart          หน้า 1
    round_gauge.dart        หน้า 2
    pro_pages.dart          หน้า 3–6 (Sweep / Arc / Yellow / Bars)
    pro_pages2.dart         หน้า 7–9 (Red stripe / ECU / Center tach)
    picture_dash.dart       หน้า 10
    settings_page.dart      MENU (การเชื่อมต่อ/หน้าปัด/เกียร์/รูป/DTC)
    live.dart               ตัวทำให้ค่าวิ่งนุ่ม (สปริง) + วาดทุกเฟรม
android/app/src/main/kotlin/.../MainActivity.kt   Bluetooth SPP + ผูก WiFi
esp32/N1V65Link.h           ไฟล์เสริมสำหรับ ESP32 CYD
```

PID ที่อ่าน: 0C รอบ · 0D ความเร็ว · 05 น้ำ · 0F IAT · ATRV แบต · 04 load · 11 TPS · 0B MAP · 10 MAF · 2F น้ำมัน
(แอปอ่านรอบกับความเร็วทุกรอบ ส่วนค่าอื่นสลับกันอ่านทีละค่า ถ้ารถไม่รองรับค่าไหนจะข้ามค่านั้นไปเอง)

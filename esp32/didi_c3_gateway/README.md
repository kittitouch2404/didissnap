> **อัปเดต: ส่งทาง Bluetooth (BLE) แทน ESP-NOW แล้ว** — จอ S3 4.3", จอ CYD 2.8" และแอปแอนดรอยด์ ต่อ C3 พร้อมกันได้ 3 จอ ไม่ต้องใช้ WiFi
> ต้องลงไลบรารี **NimBLE-Arduino (by h2zero) 2.x** · ชื่อที่ C3 ประกาศ: `Didissnap-C3` · ESP-NOW แบบเดิมเปิดได้ที่ `USE_ESPNOW 1`
> แอป: MENU → การเชื่อมต่อ → แหล่งข้อมูล "ESP32-C3 ที่ช่อง OBD2 (Bluetooth BLE)"
> จอ S3: เมนู OBD → OBD SOURCE: C3 · จอ CYD: ตั้ง `#define OBD_LINK_C3 1`

> **ปรับค่า gain / offset ที่ C3:** ตั้งจากแอป (ตั้งค่า → ปรับค่าให้ตรงที่ C3) หรือเมนู CALIBRATE ของจอ S3 — C3 จำไว้ในตัว ทุกจอได้ค่าที่ปรับแล้วเหมือนกัน

# didi_c3_gateway — ESP32-C3 Super Mini ที่ช่อง OBD2

อ่านค่าจากรถเอง (CAN หรือ K-line) แล้วส่งทาง ESP-NOW ให้จอ 4.3" (S3) และจอ CYD 2.8" — ไม่ต้องใช้ตัวอ่าน ELM327 / Bluetooth

## ตั้งค่า Arduino IDE
- Board: **ESP32C3 Dev Module** (esp32 by Espressif 3.x)
- USB CDC On Boot: **Enabled** (ดูข้อความใน Serial Monitor 115200 ผ่านสาย USB)
- Partition Scheme: Default 4MB
- ไม่ต้องลงไลบรารีเพิ่ม

## ต่อสาย
| จาก | ไป |
|---|---|
| SN65HVD230 CTX | GPIO4 |
| SN65HVD230 CRX | GPIO5 |
| SN65HVD230 3V3 / GND | 3V3 / GND ของ Super Mini |
| CANH / CANL | OBD ขา 6 / ขา 14 (ไม่ใส่ 120 Ω) |
| โมดูล K-line ขาออก (สัญญาณจากรถ) | GPIO20 ⚠ ถ้าเป็น 5V ต้องแบ่งแรงดันก่อน |
| โมดูล K-line ขาเข้า (ส่งไปรถ) | GPIO21 |
| โมดูล K-line K / + / − | OBD ขา 7 / 12V หลังฟิวส์ / GND |
| GND | OBD ขา 4 และ 5 ต่อรวมกันทั้งหมด |
| วัดแบต: 12V (หลังฟิวส์) ─[100k]─ GPIO3 ─[18k]─ GND | ใส่ตัวเก็บประจุ 100nF คร่อม 18k ได้ (ค่านิ่งขึ้น) |

## ประหยัดแบตตอนดับรถ (ค่าเริ่มต้น: ไม่ต่อสายวัดแบต, USE_VBAT 0)
- ไม่ได้ยินรถ 3 นาที → หลับลึก (ปิด WiFi, ไฟ LED ดับ)
- ตื่นทุก 60 วินาที ลองเรียกรถด้วยโปรโตคอลที่เคยต่อได้ (~3 วินาที ไม่เปิด WiFi) ไม่ตอบ → หลับต่อ
- บิดกุญแจ ON → ภายใน ~1 นาที C3 ตื่นมาต่อรถเอง

## ถ้าต่อสายวัดแบตเพิ่ม (ตั้ง USE_VBAT 1)
- ไม่ได้ยินรถ 3 นาที และแบต < 13.0V (เครื่องไม่ติด) → หลับลึก ตื่นเช็กแบตทุก 20 วินาที (ไม่เปิด WiFi)
- แบต ≥ 13.0V (สตาร์ทเครื่อง ไดชาร์จทำงาน) → ตื่นทำงานเอง
- แบต < 12.0V → หลับยาว ตื่นเช็กทุก 5 นาที (กันแบตหมด)
- ไม่ได้ต่อสายวัดแบต → หลับเมื่อไม่ได้ยินรถ 3 นาที ตื่นมาลองเรียกรถทุก 60 วินาที
- ค่าตั้งอยู่บนสุดของไฟล์ .ino (RUN_V, LOWBAT_V, IDLE_SLEEP_S, WAKE_S)

ต่อสลับ RX/TX ก็ไม่เสียหาย — แก้ `PIN_K_RX` / `PIN_K_TX` ในไฟล์ .ino แล้วแฟลชใหม่

## การทำงาน
- เปิดเครื่อง → หารถเอง: CAN 500k → CAN 250k → K-line fast init (KWP2000) → K-line slow init (ISO 9141 / KWP) แล้ววนใหม่
  - CAN ฟังบัสก่อน (ไม่ส่งอะไรออก) เพื่อไม่ให้รบกวนรถถ้าความเร็วบัสไม่ตรง
- ลำดับถาม: รอบ → TPS → AFR → รอบ (ทุกชุดที่ 4 ถามค่าช้าแทน: ความเร็ว น้ำ อากาศเข้า ฯลฯ) ข้าม PID ที่รถไม่รองรับ
- ส่งค่า ~30 ครั้ง/วินาที ช่อง WiFi 1
- อ่าน/ลบ DTC ได้จากจอทั้งสอง

## ไฟ LED บนบอร์ด
- กระพริบเร็ว = กำลังหารถ
- ติดค้าง (ดับแว็บทุกวินาที) = ได้ค่าจากรถ
- กระพริบช้า = โหมดจำลอง (DEMO)

## โหมดจำลอง (ทดสอบจอโดยไม่ต่อรถ)
- กดปุ่ม BOOT ค้าง 2 วินาที = สลับ DEMO ↔ รถจริง (จำไว้ข้ามการปิดเปิด)
- หรือตั้งที่จอ 4.3": เมนู OBD → OBD SOURCE = **C3 DEMO** (จอสั่ง C3 เอง)

## จอ 4.3" (Didissnap_S3)
- เมนู OBD → OBD SOURCE: OFF / BLE / **C3** / **C3 DEMO** (เปลี่ยนแล้วบอร์ดรีสตาร์ท)
- โหมด C3 ไม่เปิด Bluetooth → RAM เหลือให้วาด 2 คอร์
- ค่า CALIBRATE ยังใช้ได้ตามเดิม · จอ S3 ส่งค่าที่ปรับแล้วต่อให้จอ CYD

## จอ CYD
- ได้ยินจอ S3 → ใช้ค่าจาก S3 (ปรับ CALIBRATE แล้ว) · ไม่มี S3 → ใช้ค่าจาก C3 ตรง (มุมจอขึ้น C3 OK / C3 DEMO)

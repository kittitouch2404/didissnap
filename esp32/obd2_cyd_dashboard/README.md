# ESP32 CYD OBD2 Dashboard

บอร์ด ESP32-2432S028 (CYD 2.8")

## รับค่าจากบอร์ด S3 ทาง ESP-NOW (ค่าเริ่มต้น)
- `#define LINK_ESPNOW 1` (บนสุดของ .ino): จอนี้ไม่ต่อ OBD เอง รับค่ารถจากบอร์ด Didissnap_S3 (S3 ต่อตัวอ่าน OBD แบบ BLE แล้วกระจายค่า ~30 ครั้ง/วินาที)
- ไม่ต้องตั้งค่าอะไร: เปิดทั้งสองบอร์ด จอนี้หาช่อง WiFi ของ S3 เอง (ปกติช่อง 1) มุมจอขึ้น OBD OK / S3 DEMO / NO OBD (S3 ยังต่อรถไม่ติด) / NO LINK (ไม่ได้ยิน S3)
- เมนู Bluetooth = หน้าสถานะ LINK (ESP-NOW): เห็นว่าได้ยิน S3 ไหม ช่องที่ใช้ และจำนวนข้อมูล/วินาที
- เมนู DTC ใช้ได้เหมือนเดิม (จอนี้ขอให้ S3 อ่าน/ลบรหัสให้)
- ไม่ใช้ Bluetooth แล้ว = แรมเหลือมากขึ้น โปรแกรมเล็กลง ~200 KB หน้า GIF / หน้าตัวละครใช้ได้ตามเดิม
- `didinow.h` ต้องเป็นไฟล์เดียวกับในโฟลเดอร์ Didissnap_S3
- อยากกลับไปต่อ ELM327 Bluetooth เองแบบเดิม: ตั้ง `LINK_ESPNOW 0`

## หน้าจอ (ปัดซ้าย/ขวาเพื่อสลับ) พื้นดำทั้งหมด
1. หน้า 1: ตัวละคร 12 หน้า เปลี่ยนใบหน้าตามรอบเครื่อง (แบ่ง 0..redline เป็น 12 ช่วงเท่า ๆ กัน: redline 7500 = ช่วงละ 625 รอบ)
   + เลขรอบใหญ่ / แถบรอบมีแสงวิ่ง / ไฟ shift 10 ดวง / ความเร็ว / ช่องล่าง 2 ช่อง **แตะเพื่อสลับค่า** (COOLANT -> IAT -> BATT -> LOAD -> TPS -> MAP -> MAF -> FUEL -> STFT จำค่าที่เลือกไว้)
   ถึง redline: ตัวเลขสั่น+แดง ขอบจอวาบแดง | น้ำร้อนแต่ไม่ได้แสดงอยู่: ขึ้น HOT! ที่มุมบน
   เปลี่ยนรูป/ลำดับใบหน้า: `python make_face_page.py` (ดูหัวไฟล์) ได้ face_bg.h + faces.h วางทับในโฟลเดอร์สเก็ตช์
2. หน้า 2: GIF นักเรียนเต้นเต็มจอ (dance.h 88 เฟรม 10 fps ภาพ 16:9 ตัดกลางเป็น 4:3 แล้วย่อเป็น 320x240) ค่าซ้อนทับด้านบนแบบหน้ารถวิ่งเดิม: RPM + COOLANT + แถบรอบ + สถานะ (REDLINE ตอนถึง redline)
   GIF ขยับทั้งจอ จึงวาดเฟรมละ 4 แถบจากบนลงล่าง: ถอดทีละแถบลงสไปรท์ในแรมกลาง (~45 KB) (แถบแรกวาดตัวเลขทับก่อน) แล้วดันขึ้นจอทีเดียวต่อแถบ หัว/ลำตัวจึงอัปเดตพร้อมกัน ถ้าบอร์ดตามไม่ทัน 10 fps (เฟรมช้าลง) ลด `--frames` / `--q` ของ GIF
   เปลี่ยนภาพ: `python tools/make_dance_page.py ภาพ.gif . --q 72` (GIF อะไรก็ได้ ถ้าไม่ใช่ 4:3 จะตัดกลางภาพให้เอง ถ้าแฟลชไม่พอ ใช้ `--frames 40 --q 70`) ได้ dance.h วางทับในโฟลเดอร์สเก็ตช์
3. หน้า 3: แถบรอบสีฟ้าด้านบน + ความเร็วกล่องเหลือง + เกียร์กล่องฟ้า + ช่องเหลือง
   (WATER T / AIR T / ENG LOAD / AIRFLOW / FUEL % / r/min / BATT V / BOOST / TRIP km)
4. หน้า 4: แท่งรอบโค้งแบบจอรถแข่ง (0-3000 ส่วนโค้งสีขาว, เกิน 3000 ส่วนตรงสีเหลือง, โซน redline สีแดง)
   + ความเร็วใหญ่ + เกียร์ + ตารางเลขเซเว่นเซกเมนต์ (WATER / RPM / BATT / TPS / BOOST / TRIP)
5. หน้า 5: เกจครึ่งวงแหวน (เหลือง = รอบ, ขีดแดงที่ปลาย) + เกียร์กลางวง + บูสต์ + กล่องความเร็ว + แบต + แถบน้ำ 0-120
6. หน้า 6: หน้าปัดกลม (เดิม)  7. หน้า 7: ไมล์แบบแถบ (เดิม)
8. หน้า 8: จอแข่งสีส้ม (สไตล์ dash รถแข่ง) ไฟ shift สี่เหลี่ยม 13 ดวงด้านบน (เริ่มติดที่ 50% ของ redline: เขียว-ส้ม-แดง, ถึง redline กะพริบแดง/ฟ้า)
   + แถบรอบส้ม + รอบ r/min + "Race" + เกียร์ตัวเอียงใหญ่
   ซ้าย: Water TMP / Air TMP / Air Press (MAP เป็น bar สัมบูรณ์) / AIR FLOW (g/s)
   ขวา: Km/h / ENGINE L (โหลด %) / Short FT (short term fuel trim % จาก PID 06) / Batt Vol
9. หน้า 9: เกจโค้ง 240 องศา (ฟ้า = รอบ, แดง = โซน redline) + เข็มส้ม + เกียร์ในวงกลม + ความเร็ว
   ขีดเหลืองบนวงแหวน = รอบสูงสุด, บรรทัดล่าง PEAK = รอบ/ความเร็วสูงสุด
   ขวา: COOLANT (MAX) / IAT (MAX) / VOLT (MIN) ตัวเลข + แถบ + ขีดเหลืองที่ค่าสูงสุด/ต่ำสุด
   ค่าสูงสุด/ต่ำสุดเริ่มนับใหม่ทุกครั้งที่ต่อ OBD ติด (หรือเริ่มเดโม) สเกลสูงสุด = redline ปัดขึ้น (7500 -> 8)

สเกลรอบทุกหน้าใช้ค่า MAX RPM (redline) ในเมนู: ตัวเลขสูงสุด = redline ปัดขึ้น + 2 (เช่น 7500 -> 10) ตัวเลขตั้งแต่ redline ขึ้นไปเป็นสีแดง
ถึง redline: แถบรอบกะพริบแดง ตัวเลขรอบกะพริบแดง ขึ้น REDLINE แทน OBD OK
น้ำร้อนเกินที่ตั้ง: ตัวเลขน้ำกะพริบแดง | แบตต่ำกว่า 11.8 V: ตัวเลขแบตเป็นสีแดง
เกียร์คำนวณจากรอบ/ความเร็ว (ปรับตารางได้ที่ MENU -> GEAR) | BOOST = (MAP - 101.3 kPa) / 100 เป็น bar
แต่ละหน้าอ่านเฉพาะค่าที่ตัวเองแสดง (น้ำอ่านเสมอเพื่อเตือนความร้อน) ค่าไหนรถไม่รองรับจะแสดง --

## ความลื่นของจอ (ตั้งค่าที่ต้นไฟล์/ในโค้ด)
- ELM327 ส่งค่ารอบมาเป็นจังหวะ ~10-25 ครั้ง/วินาที จอจึงไม่ใช้ค่าล่าสุดตรง ๆ แต่ **ย้อนหลังเล็กน้อยแล้วลากเส้นระหว่างค่า** (interpolation)
  ระยะย้อนหลังปรับเองอัตโนมัติ ~1.2 เท่าของช่วงห่างระหว่างค่า (30-160 ms) แล้วผ่าน **สปริงหน่วงพอดี** ให้เข็ม/แถบออกตัวและหยุดนุ่ม ไม่เด้งเกิน
  ผลทดสอบจำลอง (OBD ~12 Hz): เฟรมที่เข็มหยุดค้างระหว่างเร่ง 52 -> 0, ความกระตุก ลดลง ~13 เท่า แลกกับตามหลังค่าจริงเพิ่ม ~0.1 วินาที
- `FRAME_MS` 16 = ~60 fps (เดิม 25 = 40 fps)
- ความไวของสปริง: ใน `updateUI()` `springTo(dispRpm, ..., 30.0f)` (รอบ) และ `14.0f` (ความเร็ว) ยิ่งมากยิ่งไวแต่ลื่นน้อยลง
- ปลายแถบรอบแบบ sub-pixel: แท่ง/คอลัมน์สุดท้ายผสมสีตามเศษ (หน้า 1, 2, 3, 7) หน้า 4 และ 8 วาดวงแหวนละเอียดขึ้น (ทุก 0.25 องศา)
- `FPS_LOG` 1 = พิมพ์ลง Serial (115200) ทุก 5 วินาที: `page N: xx fps, draw avg/max ms, interp delay` ถ้า fps ต่ำกว่า ~50 ส่งตัวเลขมาดูได้

## ก้อนแรมกลาง (RAM pool)
- ตอนเปิดเครื่อง (ก่อนเปิด Bluetooth) จองแรมไว้ 1 ก้อน 48.6 KB ทุกหน้าแบ่งใช้ก้อนนี้ (จอแสดงทีละหน้า):
  หน้า 1 (ตัวละคร) และหน้า 2 (GIF) ใช้ทั้งก้อน / หน้าอื่น 13 KB -> เปลี่ยนหน้ากี่รอบก็ไม่ต้องขอแรมใหม่ ไม่มีภาพ/ตัวเลขหายเพราะจองไม่ได้
- หลังเปิด Bluetooth ถ้าแรมว่างเหลือน้อยกว่า 40 KB (`POOL_MIN_FREE`) จะเตือนใน Serial Monitor
- ดูสถานะ: MENU -> DISPLAY บรรทัด `RAM pool: 48 KB (FULL)` / `after BT:` / `free now:` หรือ Serial Monitor บรรทัด `RAM pool:` และ `after Bluetooth:`
- ปิดได้: ตั้ง `USE_RAM_POOL 0` ที่ .ino (กลับไปจองแรมทีละหน้าแบบเดิม)

## ใช้งานครั้งแรก
1. คาลิเบรตทัช: แตะลูกศรตามมุมจอ (ทำใหม่ได้โดยแตะจอค้างตอนเปิดเครื่อง)
2. เสียบ ELM327 ที่รถ เปิดสวิตช์รถ และปิด Bluetooth มือถือที่เคยจับคู่กับมัน
3. MENU -> BLUETOOTH -> SCAN -> แตะชื่อ ELM327 (ถ้าต่อไม่ติด ลอง PIN 0000)
4. มุมจอขึ้น OBD OK = ต่อสำเร็จ (ครั้งต่อไปต่อเอง)

## การใช้งาน
- ปัดซ้าย/ขวา: สลับหน้า (จำหน้าที่ดูล่าสุดไว้ เปิดเครื่องครั้งหน้ากลับมาหน้าเดิม)
- **ปัดขึ้น (ลากนิ้วขึ้นจากตรงไหนก็ได้): เปิดเมนู** เมนูเลื่อนขึ้นจากขอบล่าง | **ปัดลง: ปิดเมนู** กลับหน้าเดิม
  (สำรอง: แตะมุมขวาบนของจอก็เปิดเมนูได้)
- เมนูเป็นรายการ 7 ข้อ แต่ละข้อมีคำอธิบายว่าตั้งอะไร + ค่าปัจจุบันด้านขวา แตะข้อไหนเพื่อเข้าไปตั้ง:
  1. MAX RPM: รอบ redline (จุดที่ไฟ shift / โซนแดงเริ่ม) 2000-10000 ทีละ 250
  2. COOLANT ALERT: อุณหภูมิน้ำที่ให้ตัวเลขกะพริบแดงเตือน 70-130 องศา
  3. DISPLAY: ความสว่าง / AUTO ตามแสง / FLIP 180 / DEMO
  4. BLUETOOTH: ค้นหา/จับคู่ ELM327 (ด้านขวาแสดงสถานะ OBD สด)
  5. ENGINE CODES: อ่าน/ลบรหัสปัญหาเครื่องยนต์ (DTC)
  6. GEAR: ตารางอัตราทดเกียร์สำหรับคำนวณเกียร์
  7. PEAKS: ค่าสูงสุด/ต่ำสุด (ทริปนี้ และตลอดการใช้งาน)
  หน้าตั้งตัวเลข (ข้อ 1-2): แตะ - / + หรือกดค้างให้เปลี่ยนเร็ว แล้วแตะ DONE (บันทึกทันที)
- หน้า 6: แตะช่อง TRIP = รีเซ็ตระยะทริป
- MENU -> DISPLAY -> FLIP 180: กลับจอ 180 องศาทันที (จำค่าไว้ เปิดเครื่องครั้งหน้ายังกลับอยู่) แตะอีกครั้งเพื่อกลับคืน
  ถ้ากลับจอแล้วแตะผิดฝั่ง (ทัชไม่กลับตาม) ให้ตั้ง `TOUCH_FLIP_FIX` เป็น 1 ที่ต้นไฟล์ .ino

## ปรับแต่งที่ต้นไฟล์ .ino
- `OBD_NAME`, `DEF_MAX_RPM`, `DEF_TEMP_ALERT`
- `SPLASH_MS` ความยาวหน้าเปิดเครื่อง (หน้าปัดจะแบ่งขีดตามค่า redline ที่ตั้งไว้)
- `LOGO_FADE_MS` / `LOGO_HOLD_MS` / `LOGO_OUT_MS` หน้าโลโก้: เวลาค่อย ๆ สว่าง / ค้าง / มืดลง (เปลี่ยนรูป: `python tools/make_logo.py รูป.jpg logo.h` ลบ logo.h ออก = ไม่มีหน้าโลโก้)
- `LDR_DARK` / `LDR_BRIGHT` สลับกันถ้าโหมด AUTO ทำงานกลับด้าน
- **จอกลับด้าน / ตัวหนังสือกลับซ้าย-ขวา / ภาพไม่เต็มจอหรือหมุนไป 90 องศา**: มักเป็นเพราะชนิดจอไม่ตรง
  ตั้ง `PANEL_ST7789` เป็น 1 (ค่าเริ่มต้นตอนนี้) ถ้ายังผิด ลองเป็น 0 สลับกัน
  แล้วลองเปลี่ยน `LCD_ROTATION` ทีละค่า (3 -> 1 -> 7 -> 5) เปลี่ยนแล้วบอร์ดจะให้คาลิเบรตทัชใหม่เอง
- สีเหมือนฟิล์มเนกาทีฟ (ท้องฟ้ากลางคืนกลายเป็นสีอ่อน): สลับ `LCD_INVERT` (ตั้งต้นตอนนี้ 0)  |  แดง-น้ำเงินสลับกัน: ตั้ง `LCD_RGB_ORDER` เป็น 1
- เปิด Serial Monitor (115200) ตอนบูตจะพิมพ์ `LCD 320x240 rotation=... panel=...` ควรได้ 320x240

- **ใช้ไปสักพักแล้วจอค้าง/รีบูตเอง**:
  - ดู MENU -> DISPLAY บรรทัด `Last reset:` (สาเหตุล่าสุด เช่น BROWNOUT = ไฟตก, TASK_WDT/PANIC = โปรแกรมค้าง/ล้ม, LOW_HEAP = โค้ดรีสตาร์ตเองเพราะแรมต่ำ), `crashes:` (จำนวนครั้ง) และ `Min heap:`
  - BROWNOUT: ไฟเลี้ยงไม่พอ ใช้อะแดปเตอร์ 5V 2A คุณภาพดี สาย USB สั้นและหนา ลองคาปาซิเตอร์ 470-1000uF คร่อม 5V/GND
  - ต่อ Serial Monitor (115200) จะเห็น `reset reason:` ตอนบูต และ `heap free/min/largest` ทุก 5 วินาที ถ้าค่า free ค่อยๆ ลดลงเรื่อยๆ = แรมรั่ว ส่งตัวเลขมาให้ผมดู
  - เลือกอุปกรณ์ในเมนู BLUETOOTH ให้เรียบร้อย (บันทึก MAC) จะต่อเร็วกว่าและไม่ต้องสแกนซ้ำ
  - ถ้ารีบูตเพราะค้าง บอร์ดจะข้ามโลโก้เพื่อกลับมาใช้งานไวขึ้น

## Partition แบบ Custom (partitions.csv)
- ไฟล์ `partitions.csv` ในโฟลเดอร์สเก็ตช์: พื้นที่โปรแกรม 3,968 KB (เกือบทั้งแฟลช 4MB) ไม่มี OTA / SPIFFS
- nvs อยู่ที่ 0x9000 เท่าเดิม -> ค่าในเมนูและคาลิเบรตทัชไม่หาย
- ใช้: Tools -> Partition Scheme -> **Custom** แล้วอัปโหลดตามปกติ
- ถ้าเลือก scheme อื่น ไฟล์นี้ก็ยังถูกใช้ แต่ IDE จะเช็กขนาดตาม scheme ที่เลือก (เช่น 2MB) -> ต้องเลือก Custom ถ้าโปรแกรมใหญ่เกิน
